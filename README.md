# Sword Mod

A simple mod that adds 3 new swords to the game:

- Ruby Sword
- Obsidian Sword
- Emerald Sword

The swords are available in Creative Mode (the `Sword Mod` tab) and can also be crafted in Survival.

## Requirements

- Minecraft `1.21.11`
- Fabric Loader
- Fabric API
- Java `21`

## Installation

1. Install Fabric Loader for Minecraft `1.21.11`.
2. Install Fabric API for the same game version.
3. Copy `sword-mod-1.0.0.jar` into your `mods` folder.
4. Launch Minecraft using the Fabric profile.

## How to get the swords

### Ruby Sword

```
 R
 R
 S
```

- `R` = Redstone Block
- `S` = Stick

### Obsidian Sword

```
 O
 O
 S
```

- `O` = Obsidian
- `S` = Stick

### Emerald Sword

```
 E
 E
 S
```

- `E` = Emerald
- `S` = Stick

## If the mod does not show up in-game

- Make sure the mod version matches your Minecraft version (`1.21.11`).
- Make sure Fabric API is installed.
- Check that the `.jar` file is inside the `mods` folder (not inside another archive/folder).
- Restart the game after installation.
